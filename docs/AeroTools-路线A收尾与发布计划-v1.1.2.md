## 4. 阶段 R2：微信真机回归合并清单（一次覆盖三版）

### 4.1 v1.1.0 单位换算

- [ ] 首页进入"单位换算"。
- [ ] 六类（ft/m、NM/km、kt/km/h、inHg/hPa、lb/kg、℃/℉）双向各输入一次，两侧同步更新。
- [ ] 温度允许负数；其余五类输入负数被拒。
- [ ] 空值/无效输入不显示结果，且不残留上一次结果。
- [ ] 精度抽查：inHg→hPa 一位小数、hPa→inHg 两位小数、℃/℉ 一位小数。

### 4.2 v1.1.1 搜索与详情

- [ ] 全拼搜索（如 `shoudu`）、拼音首字母（如 `bj`）、曾用名（如 `地窝堡`）、英文（如 `beijing`）。
- [ ] 归一化输入：全角 `ＰＥＫ`、`P.E.K`、`ZB-AA` 与规范写法等价。
- [ ] 详情页：度分坐标、海拔 m/ft 双单位、IANA 时区 + `UTC±HH:MM`、夏令时提示、资料截至日期。
- [ ] 缺失字段显示 `—`/`暂无可靠数据`，不出现 `0`。
- [ ] **iOS 真机重点**：时区偏移显示正确（构建期查表，不依赖 Intl）。

### 4.3 v1.1.2 时间计算交互（本版专项）

- [ ] 连续多步运算时键盘与主显示区**固定底部不动**，不随计算链增长顶移。
- [ ] 计算链最新一条置顶，超过 8 条只显示最近 8 条并提示"更早见历史"；历史记录展开滚动正常。
- [ ] 键盘无 ✓ 键，布局为 `7 8 9 ⌫ / 4 5 6 C / 1 2 3 0 / ＋－各跨两列`。
- [ ] 切类型自动重校验：`9930`（时刻非法）切到时长自动提交为 `99:30`；`2461`（分钟非法）切换后错误提示随新类型刷新。
- [ ] 缓冲不足 4 位按 ＋/－ 出现"输入不完整"提示（`incomplete` 路径仍可达）。

### 4.4 通用项

- [ ] 浅色/深色主题切换，深色下底部固定区（dock）背景与对比度正常。
- [ ] 系统最大字体下各页面可用，关键信息不被截断（v1.1.2 dock 区高度重点：显示卡带错误/提示行时约 890rpx < 预留 940rpx）。
- [ ] 首页文案"时间与航路，尽在掌握"、设置页三来源说明与 `270/270` 覆盖状态（v1.0.2 回归抽查）。
