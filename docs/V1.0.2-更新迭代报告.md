## 3. 主线成果（v1.0.2 本体）

- **名录对账**：人工逐页核对民航局运输机场名录（截至 2025-12-31，27 页 × 10 条），快照入库 `airport-data/caac-registry.json`。对账期间发现该站 CDN 新旧快照混杂，第 9 页经三重交叉验证恢复（库内差集反推 + 官方吞吐量排名表 253 条全落其中 + 禁缓存直读），方法与证据链完整存档。
- **33 起官方确认更名**：旧名写入 `aliases`，机场详情卡片新增**曾用名**栏位（仅有值时显示）——乌鲁木齐地窝堡→天山国际、运城张孝→盐湖国际、加格达奇嘎仙→大兴安岭鄂伦春等。
- **34 家在册机场补齐**：总数 519 → 553；无法可靠确认的海拔（9 家）与 ICAO（蚌埠滕湖）按契约留空。
- **数据契约放宽**：仅中文名与国家必填；在线更新校验 `validateAirportData` 同步放宽，内置与下载数据同契约。
- **构建门禁升级**：`caacRef` 恰好 270 条且与登记表一一对应、中国记录中文名唯一、空串缺失拒绝；旧"中国≥240/总数≥500"退役。`caacRef` 不进客户端数据。
- **设置页**：三来源（airportsdata / OurAirports / 民航局名录）+ "境内运输机场 270/270（截至 2025-12-31）"覆盖行；缺失字段统一显示"—"（新增 `display.dash()`，真实 0 原样显示）。
- **TDD**：先写 10 处失败测试存证（`.ai/v1.0.2/tdd/red-run-1.txt`），再实现转绿；测试 89 → **104** 项，类型检查扩展到 tests/。
- **CI**：新增 GitHub Actions 最小流水线（npm ci → vitest → type-check → H5/微信/APP 构建，完全离线）。

## 7. 遗留与风险

- **推送受阻（等用户操作）**：本机 PAT 无 `workflow` 权限，GitHub 拒收含 `.github/workflows/ci.yml` 的提交；需在 GitHub 令牌设置中勾选 `workflow` 后重试。
- **真机验收（v1.0.2 退出条件）**：Android/iOS/微信三端飞行模式清单未开始；候选包需 HBuilderX，iOS 依赖 Apple 开发者账号（未就绪走计划降级路径）。**验收通过前不打 v1.0.2 标签、不开始 v1.1.0**。
- **建议上线前按官方 AIP 复核**：河池 HNI（AD 单方权威改写）、海西茫崖 HTT（OA 单源回落）两处 IATA。
- **如实留空项**：29 条海拔（28 条上游无实测 + 巫山标高矛盾）、蚌埠滕湖 ICAO、三沙永兴（两上游未收录）——均为契约行为，非缺陷。
- 剩余对账队列仅字符串类差异（nameEn 拼写差异等低价值项）。
