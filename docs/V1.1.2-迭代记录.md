用户真机试用时间计算页后提出三条反馈，2026-09-15 拍板"按方案 1 执行"：

2. **计算链可读性**：链式过程线性追加，不便核对 → 最新一条置顶、限量显示。
3. **✓ 确认键无实际作用**：4 位合法数字在末位键入时即自动提交，✓ 仅重复报错 → 移除 ✓，其兜底职责由"切换单位类型自动重校验"接管，键盘重排。

## 3. 实现要点

- **底部固定区（dock）**：主显示卡 + `num-keypad` 移入 `.dock`（`position: fixed; bottom: 0`），`env(safe-area-inset-bottom)` 渐进降级双写 padding；顶部 `.top-area` 滚动区放计算链与历史；页面容器预留 `padding-bottom: calc(940rpx + safe-area)` 防遮挡（小屏机型显示卡带错误/提示行时最高约 890rpx < 940rpx 预留）。
- **计算链置顶限量**：`MAX_VISIBLE_STEPS = 8`，`steps.slice(-8).reverse()` 最新置顶；超量显示"仅显示最近 8 条，更早见历史"提示，完整过程走历史记录（50 条不变）。
- **✓ 键移除与键盘重排**：4×4 布局 `7 8 9 ⌫ / 4 5 6 C / 1 2 3 0 / ＋－（各跨两列）`；`calcInput` 删除 `ok` 分支。
- **switchKind 重校验（✓ 的兜底接管）**：切类型时对 4 位缓冲按新类型重校验——合法自动提交（如 `9930` 时刻非法 → 切时长提交 `99:30`）；非法不提交且错误码随新类型刷新（如 `2461` 分钟非法）；有累计值+待运算符时切换直接出结果；缓冲不完整仅切类型；约束外切换（时刻+ 后切回时刻）忽略。
- **`incomplete` 错误码保留**：删 ✓ 后经运算符路径仍可达（缓冲不足 4 位按 ＋/－ 触发），错误码与文案保留，勿删。
