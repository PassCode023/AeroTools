## 3. 实现要点

- **构建期拼音（§6.1）**：`airport-data/build.js` 以 `pinyin-pro@3.29.4`（MIT，固定版本，仅构建环境 `airport-data/package.json`）生成 `py`（全拼）与 `pj`（首字母），段间 `|` 分隔（机场名/城市/曾用名），小写、无声调；客户端仅字符串匹配，**运行依赖与微信产物均无拼音库**（`grep toneType|pinyin-pro` 零检出）。
- **查询归一化（§6.2）**：`normalizeQuery` = NFD 剥组合附加符（U+0300–036F）→ 全角（FF01–FF5E）映射半角 → 小写 → 剔除空格/连字符/点号类（含全角形式与 `–—−`）；查询与被搜索文本共用，仅用 ECMAScript 内建（`String.prototype.normalize` 为 ES6 标准而非 Intl）。
- **排序（§6.3）**：代码精确(1) > 代码前缀(2) > 文本/拼音段精确(3) > 前缀(4) > 包含(5)，同分按库内原始顺序，默认 limit 50。
- **时区（§6.4）**：`build.js` 用构建机 Node 完整 ICU（过程离线）对每个数据时区自 2026-01-01 起按天采样至 2028-12-31，生成跳变表（116 时区/362 跳变，`tzoffsets.json` 9.3KB）；客户端 `tzOffset.ts` 纯查表（本地日期 `getFullYear` 序列，不经 Intl），窗口外钳到端点；夏令时提示 = 当前偏移 ≠ 标准偏移（标准 = 表内最小偏移）。
- **详情**：坐标双格式（十进制 4 位小数 + 度分 0.1′ 精度，`Math.round(×600)` 天然进位）；海拔 `elevDual`（ft = m/0.3048 四舍五入）；时区行 `IANA（UTC±HH:MM）+ 夏令时提示`；`资料截至` 行取 `currentInfo().dataAsOf`。
- 搜索页占位文案与首页入口描述同步扩展（拼音/英文）。
