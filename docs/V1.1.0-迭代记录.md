## 3. 实现要点

- **常数**：`1 ft = 0.3048 m`、`1 NM = 1.852 km`、`1 kt = 1.852 km/h`、`1 inHg = 33.8638866667 hPa`、`1 lb = 0.45359237 kg`、`°F = °C × 9/5 + 32`（计划 §5.1 原值）。
- **输入解析**：`/^-?\d+(\.\d+)?$/` 全量校验——空/纯空白/`12.`/`.`/`.5`/`1e3`/`1,000`/`+5`/双符号/带单位尾巴一律无效；非温度类别负数拒绝；温度负数放行。
- **精度**：左/右单位各自精度（气压不对称：hPa 1 位、inHg 2 位）；`toFixed` 后对 `-0.0` 归一为 `0.0`。
- **无状态**：`convert()` 无内部状态，无效输入返回 null，页面将对侧清空——结构性满足"不得复用或误显示上一次计算结果"。
- **页面**：`pages/convert/convert.vue`（分类切换 chips + 双输入卡 + 公式/离线提示行），uni 原生 input 手动绑定 + `@input` 即时换算；沿用主题令牌与 button 语义。
- **入口**：首页第三张入口卡（📐，danger-soft 底色）。
