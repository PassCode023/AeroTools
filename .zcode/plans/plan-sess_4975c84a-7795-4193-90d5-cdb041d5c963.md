# AeroTools 民航工具箱 — 实施计划

## 目标

依据《民航工具 APP V1 需求调查》(20260913-FRRBO)，用 **uni-app (Vue 3 + TypeScript)** 一套代码同时产出：Android APP、iOS APP、微信小程序（另附赠 H5 版便于预览演示）。核心功能完全离线可用，机场数据库支持在线更新。

## 技术选型

- **框架**：uni-app CLI 模板（vite-ts），Vue 3 `<script setup>` + TypeScript，无重型 UI 库（自写轻量组件与样式，避免第三方库在多端的兼容坑）
- **存储**：`uni.setStorageSync` 统一封装；机场数据库**分块存储**，规避微信小程序单 key 1MB 限制
- **测试**：vitest，对纯逻辑（时间运算、机场搜索）执行 TDD（先测后码）
- **导航**：按问卷要求，首页两个大按钮进入两个功能页，无 tabBar

## 功能规格（逐条映射问卷）

### 时间计算器
- 分钟精度（不支持秒）；连续输入数字自动格式化（键入 `1425` → 显示 `14:25`）
- 操作数分**时刻**（0–23 时）与**时长**（小时可 >23），每步运算明确标注类型
- 运算模式：时刻+时长、时刻−时长、时刻−时刻（=时长）、时长±时长
- **连续多步运算**：运行结果作为下一步左操作数，界面显示步骤列表
- 跨 24:00：同时显示「累计时长」与「次日时刻」（如 23:30+02:15 = 25:45 / 次日 01:45）
- 负结果：同时显示「数学结果」与「跨日结果」（如 08:00−10:30 = −2:30 / 前日/跨日 21:30）
- 历史记录：本地保存最近 50 条，可查看/清空（问卷：有价值非必须）
- 不做 UTC/Zulu 转换（问卷明确不需要）

### 机场查询
- 实时边输边匹配（轻量防抖）：IATA、ICAO（不区分大小写、前缀/包含）、中文机场名、中文城市名
- 结果列表显示标准信息：IATA/ICAO、中文机场名、城市、国家；点开详情追加坐标、时区、海拔
- 不做最近查询、不做收藏（问卷明确不需要）

### 机场数据库
- **内置数据**：中国全部运输机场（约 260 家，字段齐全）+ 全球主要机场（合计约 1000–1300 条），字段：IATA、ICAO、中文名、英文名（外机场兜底显示）、城市、国家、坐标、时区、海拔
- **数据管道** `airport-data/build.js`：合并源数据 → 校验（IATA/ICAO 唯一、必填字段、坐标范围、中国机场数量 sanity）→ 产出「APP 内置 static 包」与「远端部署包」两份产物
- **在线更新**：静态托管 `manifest.json`（版本号/条数/时间）+ 数据 JSON；APP 启动及设置页手动检查 → 检测到新版**提示用户确认** → 任意网络下载 → 解析校验 → 分块写入本地 → 失败自动回退旧库。更新 URL 写在 `src/config.ts`，服务端未部署时静默跳过（V1 只留框架也可用）
- 数据加载策略：本地存储版本 ≥ 内置版本时用存储，否则用内置

### 页面（4 页，浅色主题，效率与视觉兼顾）
1. **首页**：APP 标题 +「时间计算」「机场查询」两个大按钮 + 底部数据库版本角标/设置入口
2. **时间计算器**：大字号双格式结果、步骤列表、数字键盘、运算符与时刻/时长切换、历史入口
3. **机场查询**：搜索框 + 实时结果列表 + 详情展开
4. **设置**：数据库版本信息、检查更新按钮、更新说明、关于

## 执行步骤

1. `git init` 并提交问卷；落盘设计文档
2. 脚手架：`npx degit dcloudio/uni-preset-vue#vite-ts app`（失败则手工搭建等价结构），安装依赖并跑通 `dev:h5`、`build:mp-weixin`
3. **TDD 时间运算核心** `timeMath.ts`：先写 20+ 用例（跨午夜加/减、负值双解读、>23h 时长、多步链、格式化），再实现
4. **TDD 机场搜索核心** `airportSearch.ts` + 数据校验
5. 制作数据集（中国全集 + 全球主要机场，主要机场中文名逐一核对），跑数据管道
6. 实现四个页面与 db/updater 逻辑
7. 验证：vitest 全绿；小程序/H5 构建成功；浏览器实测两条核心流程
8. 交付文档：README（微信开发者工具导入步骤、HBuilderX 云打包 Android/iOS 步骤、静态托管部署步骤）

## 约束与风险（请知悉）

- **本机无法打出 APK/IPA**：APP 打包需你在 HBuilderX（DCloud 账号）云打包完成，iOS 发布另需苹果开发者账号；我交付完整源码 + 操作文档
- 微信小程序正式发布需注册小程序账号，把 appid 填入 `manifest.json`
- 机场中文名基于公开资料整理，全球主要机场可保证，冷门机场建议上线前抽查
- 深色模式、UTC 转换、收藏/最近查询、秒精度按问卷结论**不做**
